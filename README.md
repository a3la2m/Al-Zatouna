## نظرة عامة

**الزيتونة** نظام إدارة مركز تعليمي يعمل كتطبيق سطح مكتب مستقل (Desktop) دون الحاجة إلى خادم خارجي أو اتصال دائم بالإنترنت. صُمّم ليكون موثوقاً وسريعاً وسهل الاستخدام، مع التركيز على سلامة البيانات المالية ودقة القيود والحسابات، ودعم كامل للغة العربية واتجاه الواجهة من اليمين إلى اليسار.

> يعمل التطبيق محلياً على جهازك: قاعدة بيانات SQLite داخل مجلد البيانات، وواجهة حديثة، ونواة Rust قوية للأعمال الحساسة.

## أبرز المزايا

- **إدارة شاملة للبيانات:** الطلاب، المدرّسون، المواد، الدورات/المجموعات، القاعات، التسجيلات، والجدولة.
- **الحضور والمتابعة:** تسجيل ومتابعة الحضور والجداول الدراسية.
- **محرك مالي دقيق:** دفتر/قيود محاسبية، مبالغ بوحدات صحيحة (minor units) لتجنّب أخطاء الكسور العشرية، وسندات قبض/صرف، مصروفات، صندوق، ومبيعات خدمات.
- **رقابة واعتماد (Maker–Checker):** إجراءات تحقق واعتماد للعمليات المالية الحساسة لتعزيز الانضباط والموثوقية.
- **تقارير وطباعة احترافية:** تقارير تشغيلية/مالية وتوليد مستندات وملفات **PDF** (سندات، إيصالات، تقارير) قابلة للطباعة.
- **النسخ الاحتياطي والنقل الآمن:** نسخ احتياطي واستعادة، وتصدير/استيراد أرشيف بيانات محمول لنقل النظام بين الأجهزة بسهولة.
- **إشعارات وتذكيرات:** إشعارات داخل التطبيق (مع شارة عدد غير المقروء)، إشعارات سطح المكتب، وتذكيرات بالمواعيد/الجلسات.
- **تكامل Telegram (اختياري):** ربط الحسابات واستقبال إشعارات/طلبات خدمة عبر بوت تيليجرام.
- **تجربة سطح مكتب مريحة:** يعمل في صينية النظام (Tray) مع إخفاء النافذة عند الإغلاق، منع تعدد النسخ (Single Instance) مع إظهار النافذة القائمة، ودعم عربي/RTL كامل وهوية بصرية موحّدة.
- **الأمان والصلاحيات:** تسجيل دخول، إدارة مستخدمين وصلاحيات، وسجل تدقيق (Audit Log) للعمليات.

## التقنيات المستخدمة

| الطبقة | التقنية |
|---|---|
| النواة والخلفية | **Rust**، منطق الأعمال والمحرك المالي، SQLite (WAL) عبر SQLx |
| غلاف سطح المكتب | **Tauri 2** (أوامر/تكامل نظام: صينية، إشعارات، نوافذ، حوار ملفات) |
| الواجهة الأمامية | **SvelteKit (Svelte 5)** + **TypeScript** + **Tailwind CSS**، واجهة عربية RTL |
| التخزين | قاعدة بيانات **SQLite** محلية (بدون خادم) |
| التقارير والمستندات | توليد وطباعة **PDF** |
| البناء والنشر | **GitHub Actions** لبناء حزم Windows وLinux |

## التحميل والتشغيل

### ويندوز (Windows)
1. حمّل أحدث مُثبّت لنظام ويندوز (NSIS `.exe`) من صفحة [**الإصدارات (Releases)**](https://github.com/a3la2m/Al-Zatouna/releases) أو من مخرجات **Artifacts** في [GitHub Actions](https://github.com/a3la2m/Al-Zatouna/actions/workflows/build-windows.yml).
2. شغّل المثبّت وأكمل خطوات التثبيت.
3. **المتطلب:** وجود [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (مثبّت افتراضياً على أغلب نسخ Windows 10/11 الحديثة).

### لينكس (Linux)
- تتوفر حزم `.deb` و`.AppImage` من الإصدارات/Artifacts (حسب بيئة البناء `ubuntu-22.04`).
- لتشغيل AppImage: امنح الملف صلاحية التنفيذ ثم شغّله مباشرة.

> ملاحظة: عند عدم وجود إصدار منشور بعد، يمكنك الحصول على آخر بناء ناجح من تبويب Actions وتحميل المخرجات (Artifacts).

## التطوير والبناء من المصدر

### المتطلبات
- [Rust](https://rustup.rs/) (stable) مع Cargo
- [Node.js](https://nodejs.org/) (يُنصح بـ LTS) و [pnpm](https://pnpm.io/)
- متطلبات Tauri 2 لنظامك: https://v2.tauri.app/start/prerequisites/

### خطوات التشغيل محلياً (تطوير)
```bash
# 1) تثبيت اعتماديات الواجهة
cd web
pnpm install

# 2) تشغيل وضع التطوير (من جذر المشروع أو عبر Tauri)
cd ..
cargo tauri dev
```

### بناء نسخة إنتاج
```bash
cd web && pnpm install && cd ..
cargo tauri build
```
ستُنتَج الحزم المناسبة لنظامك داخل `target/release/bundle/` (مثل NSIS على ويندوز، وdeb/AppImage على لينكس وفق الإعدادات).

## هيكل المشروع (لمحة)

```
.
├─ core/                 # نواة Rust: منطق الأعمال، المحرك المالي، قاعدة البيانات، التقارير، الطباعة، الأرشفة
├─ src-tauri/            # غلاف Tauri 2: الأوامر، التكامل مع النظام، الإعدادات والتغليف
├─ web/                  # واجهة SvelteKit (Svelte 5, TS, Tailwind) — RTL
├─ docs/                 # وثائق التصميم والمعمارية (SRS, ERD, DATABASE, API, ...)
└─ .github/workflows/    # بناء ونشر تلقائي (Windows/Linux)
```
