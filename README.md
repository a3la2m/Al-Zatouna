# Education Center Management System

نظام متكامل لإدارة مركز تعليمي — تطبيق سطح مكتب مستقل يعمل محلياً بالكامل.

- **الطبقة الخلفية:** Rust + Tauri 2 + SQLite (WAL) + SQLx
- **الواجهة:** SvelteKit (Svelte 5) + TypeScript + Tailwind CSS + RTL كامل
- **الحالة الحالية:** المرحلة 1 — التحليل والتصميم (لم يبدأ كتابة الكود التشغيلي بعد)

## القاعدة الذهبية للمشروع

يمنع الانتقال إلى مرحلة قبل اجتياز اختبارات المرحلة الحالية، ويمنع وصف أي وظيفة بأنها "منجزة" قبل اختبارها فعلياً. التقرير الدوري لكل مرحلة يغطي: ما نُفّذ، الملفات، المهاجرات، الاختبارات ونتائجها، المشاكل المتبقية، القرارات الهندسية، والخطوة التالية.
